---
description: Wczytaj tylko sekcję specyfikacji po ID
---

Użyj `scripts/spec.sh $ARGUMENTS` i przeczytaj wyłącznie zwróconą sekcję.
Gdy nie znasz ID, najpierw `scripts/spec.sh --find "fraza"` — dostaniesz same
pliki i nagłówki. Nie otwieraj całych plików z `specification/`. Odpowiedz
zwięźle, podając ID i ścieżkę pliku.
